How to put these in Figma

  1. I-click ang screen sa taas para buksan full-size sa Chrome.
  2. Option A — Plugin: Install html.to.design in Figma → paste the local file URL.
  3. Option B — DevTools: Right-click #figma-export → Capture node screenshot.
  4. Design tokens are in css/tokens.css — use the same hex values for Figma color styles.

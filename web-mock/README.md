# SmartFlow — Web HTML mock (React twin for Figma)

Static **desktop frames** that mirror the live web app (`web/` React).

> Phone / Flutter mocks: **`mobile-mock/`**

## Open (no server)

Double-click **`index.html`** in Chrome. Scroll the gallery — previews show immediately.

Same for mobile: open `mobile-mock/index.html`.

## Repo map

| Folder | Role |
|--------|------|
| `mobile/flutter/` | Live mobile |
| `mobile-mock/` | Phone HTML → Figma |
| `web/` | Live React web |
| `web-mock/` | Desktop HTML → Figma |
| `backend/` | Shared API |

## Figma

Open a screen full-size from the gallery label → DevTools → capture `#figma-export` (1280×800 canvas).

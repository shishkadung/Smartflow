# SmartFlow Use Case Instructions

## Accounting
- **Create Document**: Register new document, system generates DOC-ID
- **Print QR Label**: Generate SF1 signed token, print and attach to physical folder
- **Reprint Label**: Issue new token when label is damaged or expired

## Staff/Clerk  
- **Scan IN**: Record document arrival at office (scans QR, verifies token)
- **Scan OUT**: Record document departure to another office (selects destination)
- **View Document History**: See movement trail of any document

## Department Head
- **Scan IN**: Receive documents (same as Staff)
- **Scan OUT**: Forward documents (same as Staff)
- **View Alerts**: Monitor stuck/lost documents in your office
- **Track Location**: Find current location of any document
- **View Document History**: Full movement audit trail

## System Admin
- **Monitor Scans**: Dashboard view of all scan activity (accepted/rejected)
- **View Suspicious**: Detect users with 3+ failed scans
- **Export Audit CSV**: Download scan history for compliance records
- **Reprint Label**: Override to reprint any document's QR label

## COA Auditor
- **View Audit Reports**: Access all scan logs with timestamps
- **Verify Compliance**: Check custody rules were followed
- **Access Trail**: See complete document lifecycle
- **Generate Report**: Export findings for COA submission
- **Track Location**: Real-time tracking of document locations

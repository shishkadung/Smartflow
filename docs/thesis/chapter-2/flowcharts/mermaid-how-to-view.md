# How to view Mermaid flowcharts

1. Open a figure file (e.g. `figure-2-5-department-member.md`).  
2. **Cursor** → Markdown **Preview**.  
3. Or copy the `mermaid` block → [https://mermaid.live](https://mermaid.live) → **Export PNG** → insert in Word.

## Shape map

| In Mermaid | Word shape |
|------------|------------|
| `([START])` | Oval (terminal) |
| `[Process]` | Rectangle |
| `{Question?}` | Diamond |
| `-->|Yes|` | Labeled arrow |

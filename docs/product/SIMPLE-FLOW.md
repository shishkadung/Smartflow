# SmartFlow — Simple lang (basahin ito lang)

**Isang rule:** *Sino ang may hawak ng folder, siya ang nag-Register + QR. Kung wala pa sa iyo, **Document requests** muna.*

---

## Dalawing button sa utak mo

```
┌─────────────────────────────────────┐
│  Wala pa sa desk ko ang folder      │
│  → DOCUMENT REQUESTS                │
│     (ticket sa tamang office)       │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│  Nasa desk ko na ang folder         │
│  → REGISTER (QR ID)                 │
│  → SCAN: IN / OUT kapag lumipat     │
└─────────────────────────────────────┘
```

**Huwag:** Request sa Budget tapos Register DV sa ENG — magkaiba yan.

---

## Neil (Engineering) — examples

| Situation | Gawin |
|-----------|--------|
| "Kailangan namin budget file mula Budget" | **Requests** → Budget. **Hindi** Register. |
| Budget nag-approve | Karaniwan: **BUD → ACC → ENG** (Accounting muna) |
| Budget nag-reject | **My requests** → **declined** (rejected) |
| Budget nagpadala, dumating ang folder | **Scan** → Mark **IN** (tamang office lang) |
| "May DV project packet kami sa ENG" | **Register** → type **DV** → QR |
| DV papunta Budget | **Scan** → Mark **OUT** → pili **BUD** |

## Angel (Budget) — examples

| Situation | Gawin |
|-----------|--------|
| May request mula ENG | **Requests** → Inbox → **Approve** |
| Budget file nasa Budget na | **Register** → **Approved Budget** → QR |
| Papadala (client: via ACC) | **Scan** → **OUT** → pili **ACC** (then ACC → ENG) |
| Tapos na | **Requests** → **Fulfill** + DOC ID |

---

## Tabs — ano ang gamit

| Tab | Kailan |
|-----|--------|
| **Home** | Overview + incoming folders |
| **Scan** | May DOC-ID/QR na — IN o OUT |
| **New** | **Bagong** folder sa **desk mo** — Register |
| **History** | Tingnan trail |
| **Alerts** | Delayed |

---

## Demo bukas (main = DV, 5–10 min)

2. Angel: **IN** → **OUT** → ACC  
3. **`accounting.staff`**: **IN** → History *(hindi accountant.main — admin hindi makakapag-scan)*

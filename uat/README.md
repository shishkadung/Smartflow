# SmartFlow user acceptance test (UAT)

Materials for testing SmartFlow with real users from the Municipality of Urbiztondo. Kept outside `docs/` on purpose.

| File | For | What it is |
|---|---|---|
| `1-UAT-Facilitator-Guide.docx` | the team | Preparation checklist, test data sheet, session script, scoring rules, exit criteria (4 pages) |
| `2-UAT-Staff-Booklet.docx` | clerks | Tasks S1 to S15, SUS questionnaire, usefulness ratings, comments, problem log (print one per tester) |
| `3-UAT-Head-Booklet.docx` | department heads | Tasks H1 to H10, then the same questionnaire |
| `4-UAT-Admin-Booklet.docx` | Municipal Accountant / admins | Tasks A1 to A11, then the same questionnaire |
| `5-UAT-Results-Tracker.xlsx` | the team | Type the results here. It works out pass rates, the SUS score and whether the exit criteria are met |

Start with the facilitator guide.

Things to remember

- Testers create real records in the database. Take a backup first, and enter all results into the tracker before the demo data is refreshed (planned 10 to 11 November), because the refresh removes them.
- Booklets carry no passwords. Test accounts come from the private login sheet.
- Task wording follows the current screens (checked against the web source on 26 October 2026). If a screen changes, update the matching task before the next session.
- The booklets and the guide are plain Word files, so the team can edit them. The tracker is built around the task IDs (S1 to S15, H1 to H10, A1 to A11); if you add or remove a task, change the matching column in the tracker too.
